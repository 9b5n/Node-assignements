NodeJS Basics Assignment

This assignment contains two simple Node.js programs.

Files

app.js – Prints a welcome message.
introduction.js – Prints my basic introduction.
Requirements

Node.js should be installed on the computer.

To check Node.js:

node -v
How to Run

1. Run app.js

Open the terminal in the project folder and type:

node app.js
Output:

Hello, Node.js!
I am learning backend development
2. Run introduction.js

Run:

node introduction.js
Output:

Name: Ahtisham
Education: B.Tech
Current Learning: Node.js
Goal: Backend Developer
Commands

node -v
node app.js
node introduction.js
